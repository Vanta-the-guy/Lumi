# Lumi

Lumi is a browser-based game platform featuring over 400 games, with a collection ranging from classic favorites to popular modern browser games.

## Games

Lumi includes more than 400 games across a wide variety of genres. The library includes games similar to and inspired by popular titles such as:

* Peak
* Granny
* Minecraft
* Undertale
* Hollow Knight
* Geometry Dash
* Bloons
* Friday Night Funkin'
* FNAF
* And many more



## Features

* Over 400 games
* Large variety of genres
* Fast browser-based gameplay
* Searchable game library
* Game categories
